# CODSOFT Python Programming Internship

## Overview

This repository contains the projects completed during the CodSoft Python Programming Internship. The projects demonstrate Python programming concepts including user input, conditional statements, loops, functions, file handling, JSON data storage, and randomization.

---

## Task 1: To-Do List Application

### Description

A command-line application that helps users organize and manage their daily tasks efficiently.

### Features

* Add Tasks
* View Tasks
* Update Tasks
* Mark Tasks as Completed
* Delete Tasks
* Store Tasks Using JSON File

### Technologies Used

* Python
* JSON
* File Handling

---

## Task 2: Simple Calculator

### Description

A calculator application that performs basic arithmetic operations on user-provided numbers.

### Features

* Addition
* Subtraction
* Multiplication
* Division
* Division by Zero Handling

### Technologies Used

* Python
* Conditional Statements
* Arithmetic Operators

## Task 3: Rock Paper Scissors Game

### Description

A Python-based game where the user competes against the computer by choosing Rock, Paper, or Scissors.

### Features

* User Choice Input
* Random Computer Choice
* Winner Determination
* Interactive Gameplay

### Technologies Used

* Python
* Random Module
* Conditional Statements
