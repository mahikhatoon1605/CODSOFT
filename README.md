# To-Do List Application

## Description

This is a simple To-Do List application developed in Python. The program helps users manage their daily tasks efficiently through a command-line interface.

## Features

* Add new tasks
* View all tasks
* Update existing tasks
* Delete completed tasks
* User-friendly menu system

## Technologies Used

* Python 3

## How to Run

1. Install Python 3 on your system.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

python todo_list.py

## Example Operations

* Add a task
* View tasks
* Update a task
* Delete a task
* Exit the application
